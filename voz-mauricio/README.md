# Voz do Mauricio Júnior — FastPrev Projetos

Gravações reais para reaproveitar em novos Reels.

## Conteúdo
- `audios/marape_fechamento_fastprev.mp4` (17 s): **fechamento padrão reutilizável** —
  "Este projeto é assinado pela FastPrev Projetos. Quer conhecer mais sobre nós?
  Chame no WhatsApp 13 97410-6538. Fala com Maurício Jr."
  Pode ser usado como encerramento de qualquer projeto novo.
- `audios/marape_narracao_principal.mp4` (63 s): narração do projeto Mercadinho do Marapé.
- `audios/marape_transcricao_palavras.json`: transcrição com tempo de cada palavra
  (usada para cortar as cenas na hora certa).
- `scripts/`: código que gera o vídeo 9:16 (imagens com zoom, legendas em amarelo/branco,
  barra de progresso, cartão final e mixagem da voz a -14 LUFS).

## Como reutilizar num novo projeto
1. Grave só a narração nova (o fechamento já está pronto).
2. Peça: "monte o reel com esta narração + o fechamento da FastPrev" e envie as imagens.
3. O áudio de fechamento entra após a narração, com ~0,4 s de pausa.

Obs.: a voz é da pessoa que gravou. Use apenas em conteúdo autorizado por ela.
